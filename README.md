# 线程管理

一个用于管理线程优化模块配置的 Android 应用，采用小米 HyperOS 风格界面。

## 功能

- **配置读写**：通过 Root（`su`）读取和写入 `applist.conf`，配置路径可自定义
- **配置解析**：支持 `#游戏名`、`包名{线程名}=CPU核心`、`包名=CPU核心` 三种格式
- **游戏列表**：卡片式展示，可折叠 / 展开查看线程规则，自动识别常见渠道标识
- **搜索**：实时搜索游戏名、包名、线程名，并高亮关键词
- **编辑配置**：新增、编辑、删除游戏配置，带包名和 CPU 核心格式校验
- **批量操作**：批量删除、全选，单个或批量 JSON 导入导出与系统分享
- **自动备份**：保存前自动生成 `.tp-bak` 备份文件
- **状态检测**：检测 Root 与模块状态，读取模块信息
- **界面风格**：MIUI / HyperOS 风格，Monet 动态配色，自动跟随系统深色模式
- **错误日志**：本地记录运行错误，便于排查问题
